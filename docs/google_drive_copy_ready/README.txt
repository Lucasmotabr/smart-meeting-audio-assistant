Copy-Ready Google Docs Text

These files are plain text versions of the Google Drive documents.

Use these when copying into Google Docs so you do not get black code-block backgrounds.

Recommended copy method:

1. Open one .txt file.
2. Select the text.
3. Copy.
4. In Google Docs, use Paste without formatting:
   - Mac: Command + Shift + V
   - Windows: Ctrl + Shift + V

Then add headings manually if you want.
